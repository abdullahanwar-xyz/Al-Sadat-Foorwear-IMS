# Al Sadat Footwear IMS

Inventory Management System for Al Sadat Footwear — a shoe shop's shop-floor and accounts/finance system: inventory, sales, online orders, invoicing, customers, suppliers, payments, and financial reporting.

## Structure

- `client/` — React + TypeScript frontend (Vite)
- `ims-backend/` — Node.js/Express + Sequelize (MySQL) backend API
